# Style log: what each showcase already uses

Check before choosing a direction. A new project must differ clearly in
palette, typography, layout, imagery approach and signature feature.

## Ararat Heights (residential complex, Yerevan): done
- **Palette:** dark basalt + pink tufa + snow; dusk sky gradients
- **Type:** Forum (classical serif display), Manrope (body), IBM Plex Mono (labels)
- **Layout:** alternating dark/paper full-width bands; architect's elevation drawings
- **Imagery:** v1 illustrated in code (canvas mountains); v2 AI photo renders
- **Motion:** dusk→night light change, scroll-opening image, parallax
- **Signature:** view of Ararat from your exact floor and window
- **Features:** tower→floor→apartment picker, availability grid, filters,
  payment calculators, viewing booking, compare, location map, construction progress

## EURO.G redesign concept (windows, doors, facades): done
- **Repo / live:** branding-company/eurog-redesign-concept (Astro, static) →
  https://branding-company.github.io/eurog-redesign-concept/
- **Palette:** paper #f4f5f6 + ink #1a1d24, dark "stage" #14161b for scenes,
  teal accent #0b7a8c, warm #f0a15c for heat
- **Type:** Archivo (grotesk headlines), IBM Plex Sans (body), IBM Plex Mono (spec labels)
- **Layout:** precise technical grid, drawing language (dimension lines, section cuts)
- **Imagery:** real photos from the current EURO.G site + technical drawings in code
- **Signature:** opening A: profile cross-section assembles on scroll;
  opening B: winter night seen through the wall (thermal story)
- **Features:** configurator with live drawing + AMD estimate, savings calculator,
  systems catalogue + printable PDF tech sheets, projects map, production story,
  5-step quote with upload + measurement booking, audience paths
- **Already in:** portfolio page and the English deck (eurog-redesign, -features,
  -pages, -before-after slides)

Already used across showcases (avoid repeating): Forum serif, Manrope,
